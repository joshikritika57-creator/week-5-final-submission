# Week 5 - SPA Simulation
A responsive Single Page Application simulation built with HTML, CSS and JavaScript.

Features:
- Home, Services, About and Contact views
- Client-side hash routing
- No full-page reload between views
- Browser back/forward support
- Contact form validation
- Responsive layout
- Accessibility-friendly labels, ARIA attributes and keyboard controls
- GitHub Pages compatible routing

Hash routing is used so direct routes do not cause GitHub Pages 404 errors.
